## Discussion

After evaluating several project ideas, StudyHub was selected as the flagship portfolio project because it provides an opportunity to learn and demonstrate:

- Full-stack web development
- Database design
- REST API development
- Git and GitHub workflows
- Linux server administration
- Cloud deployment using AWS
- Containerization with Docker
- Kubernetes fundamentals

The project is intended to grow from a beginner-friendly application into a production-ready portfolio project.
